# pond-check · 鱼况体检

扫一遍你机器上所有在跑的鱼，给你一页体检报告：

**谁活着 · 今天干了啥 · 哪儿坏了 · 怎么修**

> 状态：正在开发。D1–D7 七个阶段依次交付，每个阶段测试通过才进入下一阶段。

## 它要解决什么

养 AI 鱼最疼的不是「她不够可爱」，是这三件：

1. **「看起来在跑，其实什么都没发」** —— 静默失效，只能自己翻日志
2. **「不知道她今天到底干了啥」** —— 信息散在各处，日报只覆盖一小段
3. **「装完不跑，不知道为什么」** —— ffmpeg 没装？node 被顶替？登录过期？没人告诉你是哪个

pond-check 只做一件事：**把「看不见」变成「看得见」**。

## 它不会做什么（边界写在前面）

这一点比功能重要，所以放在最前面：

- **不联网** —— 不上报、不统计、不遥测、不检查更新。一条网络请求都没有。
- **不读凭证** —— 扫到凭证文件直接跳过，连文件名都不会出现在报告里。
- **不改任何东西** —— 不装插件、不改配置、不启停鱼。它是体检，不是手术。
- **不做控制面** —— 那会把它变回一个需要维护的服务。
- **不做精确账单** —— 只做量级估算，并且明确标注「估算」。

## 用法（开发中）

```bash
node src/cli.mjs              # 扫一遍，生成报告（HTML 落在当前目录）
node src/cli.mjs --json       # 只要 JSON
node src/cli.mjs --text       # 只要可贴群的纯文本摘要

# 逃生口：自动扫没找全时，人给她指路（指了就只体检这一条）
node src/cli.mjs --root <她的目录>       # 指窝：日志/配置/判重表都在这儿找
node src/cli.mjs --log <日志文件>        # 只指日志（日志不在窝里时用）
node src/cli.mjs --dedupe <判重表文件>   # 只指判重表（名字不符合惯例时用）
```

`--help` 里有完整参数表、退出码（0 正常 / 2 参数用错 / 1 真异常）和只读承诺。
